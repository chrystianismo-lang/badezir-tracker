# Badezir Tracker

Companion de **AION 2 (global)** para quem farma mascotes e materiais.

- **Overlay** por cima do jogo com os mascotes dos mobs que você mata: nível, almas que faltam e ritmo de farm.
  Mascote no máximo vira contador de pedra (cristal de Genus Insight) por gênero.
- A **coleção de mascotes vem do próprio jogo** quando você entra no personagem — não precisa digitar nada.
- **Rota**: os melhores spots (círculos pequenos no mapa) para upar os mascotes que faltam, na sua raça.
- **Loot**: escolha um material de craft e veja no mapa o melhor lugar para farmar.
- **Atualiza sozinho**: baixa a versão nova em segundo plano e mostra as novidades depois de atualizar.

## Instalar

1. Instale o [Npcap](https://npcap.com) (o mesmo que medidores de DPS usam; opções padrão).
2. Baixe o `Badezir Tracker Setup x.y.z.exe` da [última versão](../../releases/latest) e rode.
   Instala na sua pasta de usuário, sem pedir administrador. Se o Windows avisar que protegeu o computador
   (o app não é assinado): **Mais informações → Executar assim mesmo**.
3. Deixe o AION 2 em **janela sem bordas** para o overlay aparecer por cima.
4. Abra o app **antes** de entrar no personagem (ou volte para a seleção e entre de novo).

Atalhos: `Ctrl+Shift+B` mostra/esconde o overlay · `Ctrl+Shift+K` trava o overlay (o clique passa para o jogo).

## Aviso

O app só lê, no seu PC, o tráfego do próprio jogo (como os medidores de DPS): nada do jogo é enviado para
lugar nenhum e nenhuma memória do jogo é lida ou alterada. Nenhuma ferramenta desse tipo é aprovada pela
NCSOFT — use por sua conta e risco. Dados de mascotes, spawns e drops: [metabot.gg](https://metabot.gg).
